# DAI: code examples

Code examples for the DAI course (Développement d'applications
internet) at [HEIG-VD](https://heig-vd.ch). Course site:
<https://heigvd-dai-26.github.io/>.

One directory per chapter, numbered like the chapters:

- [04 · Java I/O](04-java-io)
- [05 · Docker and Docker Compose](05-docker)
- [06 · Application protocols](06-application-protocols)
- [07 · SMTP and ncat](07-smtp-and-ncat)
- [08 · TCP and UDP programming](08-tcp-and-udp)
- [09 · Network concurrency](09-network-concurrency)

Clone this repository once, then `git pull` to get the examples of new
chapters:

```sh
git clone https://github.com/heigvd-dai-26/dai-code-examples.git
```
